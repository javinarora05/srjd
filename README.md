# 🌶️ SRGD Spices Website

> A production-oriented React website focused on responsive UI, SEO, performance and real-world deployment.

## ✨ Highlights
- React 18 + Vite frontend
- Tailwind CSS
- Framer Motion interactions
- React Router
- Dynamic SEO metadata with React Helmet Async
- Swiper product sections
- Image optimisation with Sharp
- Hostinger/shared Apache deployment setup
- Contact and distributor enquiry flows
